# سامانه مدیریت پرسنل و پست‌ها

برنامه ویندوزی (WinForms) روی .NET 9 برای مدیریت اطلاعات پرسنل و پست‌های برق (Posts) با پایگاه‌داده Microsoft Access (OLE DB)، رابط فارسی و راست‌به‌چپ (RTL).

---

## محتوای پروژه

| فایل | توضیح |
|---|---|
| `PersonnelManagementApp/` | کد اصلی برنامه |
| `PersonnelManagementApp/MyDatabase.accdb` | پایگاه‌داده Access (۹۵ پست، ۴۵۴ پرسنل) |
| `PROMPT_FA.md` | مشخصات فنی و معیارهای پذیرش |
| `setup-database-provider.ps1` | اسکریپت نصب / تعمیر موتور Access Database Engine |

---

## مشکلات برطرف‌شده

### ۱) خطای `Microsoft.ACE.OLEDB.12.0 provider is not registered`
- `DatabaseProvider.cs` خودکار بین `Microsoft.ACE.OLEDB.16.0` و `Microsoft.ACE.OLEDB.12.0` تشخیص می‌دهد.
- ناسازگاری معماری (۳۲/۶۴ بیتی) تشخیص داده می‌شود و پیام راهنما نمایش داده می‌شود.
- دکمه «نصب / تعمیر موتور ACE» در بخش تنظیمات، نصب خودکار را انجام می‌دهد(winget → نصب‌کننده رسمی x64).
- اسکریپت `setup-database-provider.ps1` نیز برای نصب دستی/خودکار موجود است (با Administrator اجرا کنید).

### ۲) کامل‌شدن بخش پست‌ها (Posts Analytics)
- **علت ناقص بودن:** کوئری قدیمی با ۱۸ کو `ری `INNER JOIN` ردیف‌هایی را که کلید خارجی صفر/null داشتند حذف می‌کرد؛ از ۹۵ پست فقط ۷۷ نمایش داده می‌شد.
- **راه‌حل:** `PostsDataService.cs` جدول `Posts` را همراه جدول‌های مرجع جداگانه بارگذاری و در حافظه ادغام می‌کند. مقادیر از دست‌رفته با «نامشخص» نمایش داده می‌شوند. اکنون هر ۹۵ پست نمایش داده می‌شوند.
- **فرم‌ها:**
  - `FormPostsAnalytics.cs` — تحلیل پست‌ها با طراحی هم‌سبک «تحلیل پرسنل»: پنل فیلترهای ۶×۲، تب‌های نمودار (۱۵ شاخص) با تغییر نوع نمودار و خروجی هرکدام، جدول‌های آمار/جزئیات ادارات/لیست پست‌ها، خروجی اکسل و **ویرایش/حذف پست از داخل پنجره جزئیات**.
  - `FormExportPostCharts.cs` — خروجی حرفه‌ای نمودار (پیش‌نمایش زنده، ذخیره PNG/JPG/BMP، پیش‌نمایش چاپ، آمار تفکیکی).

### ۳) بهبود رابط کاربری
- `MainForm.cs` — داشبورد پاسخ‌گو با هدر، کارت‌های KPI، کارت‌های اقدام گروه‌بندی‌شده و نوار وضعیت.
- `FormSettings.cs` — بازطراحی کامل و مدرن: منوی کناری گروه‌بندی‌شده، هدر یکپارچه، کارت‌های مرتب با چیدمان داکینگ و بخش وضعیت/تست/نصب موتور پایگاه داده.
- رفع چیدمان راست‌به‌چپ (`TextAlign` در RTL آینه می‌شود).

### ۴) مدیریت پست‌ها (جدید)
- `FormPostsManager.cs` — جستجو (متن آزاد + فیلتر استان)، افزودن، ویرایش، حذف چندگانه و خروجی اکسل پست‌ها.
- `FormPostsEditor.cs` — فرم افزودن/ویرایش با فیلترهای وابسته (استان ← شهر/امور ← اداره ← ناحیه ← نام پست) و همه فیلدهای فنی و ظرفیت.
- `PostsCrudService.cs` — عملیات درج/به‌روزرسانی/حذف با پارامتر و بازگشت شناسه خودکار.

### ۵) مدیریت یکپارچه پرسنل (بازطراحی)
- `FormPersonnelManager.cs` — یک داشبورد واحد برای پرسنل: جستجو (متن آزاد + فیلتر استان)، افزودن، ویرایش، حذف چندگانه و خروجی اکسل.
- `FormPersonnelEditor.cs` — فرم مدرن افزودن/ویرایش با فیلترهای وابسته، اعتبارسنجی کامل، تاریخ‌ها و مدیریت عکس.
- در داشبورد اصلی فقط یک کارت «مدیریت پرسنل» وجود دارد (به‌جای سه دکمه جداگانه ثبت/ویرایش/جستجو).
- `FormPersonnelSearch.cs` نیز به‌صورت مدرن بازطراحی شد و حذف پرسنل داخل همان جستجو ادغام شده است.
- حذف گرادیان‌های قدیمی و به‌روزرسانی پالت رنگی فرم‌های ثبت/ویرایش قدیمی.

## نحوه اجرا

### پیش‌نیاز
- .NET 9 SDK (برای ساخت) یا .NET 9 Desktop Runtime (برای اجرا)
- موتور Access Database Engine (اگر نصب نیست، به بخش بالا مراجعه کنید)

### ساخت
```bash
dotnet build PersonnelManagementApp.sln -c Debug
```

### اجرا
فایل اجرایی ساخته می‌شود در:
```
PersonnelManagementApp/bin/Debug/net9.0-windows/PersonnelManagementApp.exe
```
فایل `MyDatabase.accdb` به‌صورت خودکار در کنار فایل اجرایی کپی می‌شود.

## لیست تست دستی

### دیتابیس و Provider
1. برنامه را اجرا کنید؛ داشبورد باید «پایگاه داده متصل است» را نشان دهد.
2. به «تنظیمات ← تنظیمات دیتابیس» بروید؛ «تست اتصال» باید موفق باشد.
3. اگر وضعیت قرمز بود، «نصب / تعمیر موتور ACE» را بزنید و برنامه را دوباره اجرا کنید.

### پست‌ها (بخش کامل‌شده)
4. «تحلیل پست‌ها» را از داشبورد باز کنید.
5. کارت «کل پست‌ها» باید **۹۵** را نشان دهد (نه ۷۷).
6. فیلتر «استان‌ها» را انتخاب کنید؛ گزینه‌های «شهرها/ادارات/نواحی» باید به‌صورت وابسته به‌روزرسانی شوند.
7. روی یک قطعه از نمودار کلیک کنید؛ پنجره جزئیات پست‌های آن دسته باز می‌شود.
8. «خروجی اکسل» را تست کنید (یک فایل xlsx ذخیره شود).
9. «خروجی پیشرفته» را باز کنید؛ نمودار، آمار، ذخیره تصویر و چاپ را تست کنید.

### سایر
10. بخش پرسنل، جستجو، ثبت/ویرایش و عکس‌ها همچنان باید سالم باشند.
11. `نمودارها و جداول را در اندازه‌های مختلف پنجره بررسی کنید (نمای پاسخ‌گو).
12. در صورت بروز خطا، فایل لاگ را بررسی کنید:
    ```
    %LOCALAPPDATA%\PersonnelManagementApp\Logs\error.log
    ```
